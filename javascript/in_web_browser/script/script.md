# คู่มือใช้งานระบบเฝ้าป้ายรถเมล์ (Bus Watcher)

เอกสารนี้อ้างอิงจากสคริปต์ JavaScript ที่ให้มา โดยค่าเริ่มต้นตั้งป้ายเป้าหมายเป็น **วัดรางบัว**

## 1. เปลี่ยนชื่อป้ายรถเมล์

1. เปิดไฟล์ JavaScript ด้วยโปรแกรมแก้ไขข้อความ เช่น VS Code, Notepad หรือ TextEdit
2. มองหาบรรทัดแรก ๆ ของสคริปต์:

   ```javascript
   const TARGET = "วัดรางบัว";
   ```

3. เปลี่ยนข้อความ `วัดรางบัว` ให้เป็นชื่อป้ายที่ต้องการ โดยคงเครื่องหมายอัญประกาศคู่ไว้ เช่น:

   ```javascript
   const TARGET = "สำนักงานเขตจอมทอง";
   ```

4. บันทึกไฟล์ แล้วคัดลอก **โค้ด JavaScript ทั้งหมด** (ตั้งแต่ `(async function () {` จนถึง `})();`)

> เปลี่ยนเฉพาะชื่อป้ายในบรรทัด `const TARGET` ก็พอ ไม่ต้องเปลี่ยนชื่อในข้อความแจ้งเตือนส่วนอื่น เพราะสคริปต์นำค่าจาก `TARGET` ไปใช้โดยอัตโนมัติ

## 2. นำโค้ดไปใช้ในเว็บเบราว์เซอร์

1. เปิดเว็บไซต์ที่มีข้อมูลรถเมล์และรายการรถในรูปแบบที่สคริปต์ตรวจสอบได้
2. เปิด Developer Tools ของเบราว์เซอร์:
   - **Chrome / Edge:** กด `F12` หรือ `Ctrl + Shift + J` (Windows/Linux)
   - **Firefox:** กด `F12` แล้วเลือกแท็บ **Console** หรือกด `Ctrl + Shift + K`
   - **Safari บน Mac:** ต้องเปิดเมนู Develop ก่อน จากนั้นเลือก **Develop > Show JavaScript Console**
3. เลือกแท็บ **Console**
4. วางโค้ด JavaScript ทั้งหมดลงในช่อง Console
5. กด `Enter` เพื่อเรียกใช้สคริปต์

หากเบราว์เซอร์แสดงคำเตือนเรื่องการวางโค้ดใน Console ให้อ่านคำเตือนและทำตามขั้นตอนอนุญาตของเบราว์เซอร์เฉพาะเมื่อคุณตรวจสอบและเชื่อถือโค้ดนี้แล้ว

## 3. เริ่มเฝ้าป้าย

หลังวางโค้ดและกด `Enter` จะมีแผง **🚌 ระบบเฝ้าป้าย** ปรากฏบนหน้าเว็บ

1. ตรวจสอบชื่อป้ายเป้าหมายบนแผงควบคุม
2. กดปุ่ม **🔊 เปิดเสียงและเริ่มเฝ้าป้าย**
3. อนุญาตการแจ้งเตือน (Notification) หากเบราว์เซอร์ถาม
4. ระบบจะตรวจสอบข้อมูลทุก **10 วินาที**
5. เมื่อพบรถตามเงื่อนไขในสคริปต์ ระบบจะแจ้งเตือนด้วยเสียงและเสียงพูดภาษาไทย รวมถึง Notification หากได้รับอนุญาต

## 4. ปุ่มบนแผงควบคุม

- **รับทราบแล้ว · ปิดการแจ้งเตือน** — หยุดเสียงและปิดการแจ้งเตือนรอบนั้น
- **เฝ้าป้ายต่อ** — กลับมาเริ่มตรวจสอบป้าย
- **หยุดเฝ้าป้าย** — หยุดตรวจสอบชั่วคราว
- **ซ่อนแผงควบคุม** — ซ่อนแผง แต่ระบบยังทำงานอยู่; กดปุ่มแสดงแผงเพื่อเปิดกลับ
- **ปิดระบบทั้งหมด** — ยุติสคริปต์และนำแผงควบคุมออกจากหน้าเว็บ

## 5. ถ้าต้องการเปลี่ยนชื่อป้ายภายหลัง

1. กด **ปิดระบบทั้งหมด** เพื่อหยุดสคริปต์เดิม
2. แก้ไขค่า `TARGET` ในโค้ด
3. คัดลอกโค้ดฉบับที่แก้ไขแล้วไปวางใน Console
4. กด `Enter` แล้วกดปุ่มเปิดเสียงและเริ่มเฝ้าป้ายอีกครั้ง

## หมายเหตุสำคัญ

- ในสคริปต์ฉบับนี้ **ยังไม่มีช่องให้พิมพ์ชื่อป้ายหรือปุ่ม “Done” บนแผงควบคุม** การเปลี่ยนชื่อป้ายต้องแก้บรรทัด `const TARGET` ในโค้ดก่อนนำไปรัน
- สคริปต์ค้นหารายการบนหน้าเว็บด้วยตัวเลือก `.timeline-item` และตรวจหาข้อความชื่อป้ายเป้าหมายร่วมกับรหัสรถที่ตรงรูปแบบ `16-ตัวเลข` ดังนั้นหน้าเว็บต้องมีโครงสร้างข้อมูลตรงกับเงื่อนไขนี้ มิฉะนั้นอาจตรวจไม่พบรถ
- การทำงานจะหยุดเมื่อปิดหรือโหลดหน้าเว็บใหม่ และการทำงานเบื้องหลังขึ้นอยู่กับข้อจำกัดของเบราว์เซอร์และอุปกรณ์
- ต้องเปิดเสียงผ่านปุ่มบนแผงก่อน เพราะเบราว์เซอร์มักไม่อนุญาตให้เว็บเล่นเสียงอัตโนมัติโดยไม่มีการกดจากผู้ใช้
- ตรวจสอบโค้ดก่อนวางใน Developer Console ทุกครั้ง และอย่าวางโค้ดที่ไม่ทราบแหล่งที่มา
